# Håsand Consultancy website production backup

This branch contains the repaired, self-contained production website backed up from https://www.hasand.no on 2026-09-04.

The five website images are stored locally under `assets/images/`; the site no longer depends on the former Manus/CloudFront image URLs.

Production hosting remains on Vercel project `hasand-new`. This branch is a backup and does not control the live deployment.
